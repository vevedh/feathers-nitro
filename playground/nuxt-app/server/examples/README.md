# Server integration examples

These files are documentation examples and are not auto-loaded by Nuxt. The live playground uses the plugins in `server/plugins/`.

- `express.ts`: Express adapter plugin
- `koa.ts`: Koa adapter plugin
- `socket-io.ts`: Socket.IO adapter plugin
- `multi-instance.ts`: lifecycle setup for named applications

Copy the variant that matches your application into `server/plugins/` and adapt its application import.
